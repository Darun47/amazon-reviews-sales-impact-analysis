# Project Overview
In this project, the reviews of Amazon products are analyzed in order to comprehend the impact of customer rating, sentiment, and helpfulness on consumer trust and purchasing decision. This project aims to convert raw data in the form of review into significant insights by creating an interactive tableau dashboard.
This dashboard assists the stakeholders in knowing the customer satisfaction, review patterns as well as the performance of products. It facilitates evidence-based decision-making to enhance the quality of products and customer experience.
